# LONGVIEW · 장기투자 스쿨

미국주식 장기투자를 위한 개인 학습 웹앱입니다. 한국어 수업, 퀴즈, 계산 연습, 기업 분석 노트와 원문 자료 안내를 제공합니다.

## 매일 사용하는 주소

**[장기투자 스쿨 열기](https://longview-investing-lab.fisherpark.chatgpt.site)**

- 위 주소를 브라우저 즐겨찾기에 추가하세요. PC를 켜 두거나 로컬 서버를 실행할 필요가 없습니다.
- 현재 사이트는 소유자 전용입니다. 접근할 때 게시에 사용한 계정으로 로그인이 필요할 수 있습니다.
- `http://127.0.0.1:5173/`는 개발 중에만 실행하는 임시 미리보기입니다. 일상적인 사용에는 위 웹 주소를 이용하세요.
- GitHub는 소스와 변경 이력을 보관하는 곳이고, 실제 앱은 별도 웹 주소에서 사용합니다.

## 처음 시작하는 순서

1. **학습 대시보드 → 이어서 공부하기:** 한 개념을 읽고 퀴즈를 풉니다. 정답 확인 후 학습 완료를 누르세요.
2. **학습 로드맵:** 투자 기초 → 재무제표 → 기업가치 → 차트 → 시황 → 매크로 순서로 배웁니다.
3. **기업 분석 길잡이:** 공식 IR과 SEC 공시를 어디서 찾고 무엇을 읽을지 확인합니다. 자료마다 펼쳐 볼 수 있는 학습 방법이 있습니다.
4. **분석 실험실:** 성장률·이익률·현재가치의 입력값을 바꾸고, 이동평균선의 차이를 관찰합니다. 숫자는 가상의 학습 예제입니다.
5. **기업 분석 노트:** 관심 기업 하나의 사업모델, 투자 가설, 지표, 가격, 반대 증거, 다음 점검 항목을 작성하고 저장합니다.
6. **지식 라이브러리:** 더 배우고 싶은 주제의 원문·공개 강의·블로그를 확인합니다.

## 꾸준히 쓰는 추천 루틴

| 주기 | 할 일 | 남길 결과 |
| --- | --- | --- |
| 평일 10~15분 | 수업 한 개와 퀴즈 | 새 개념 하나 |
| 주말 30분 | 공식 자료 한 개 읽고 관심 기업에 적용 | 분석 노트의 질문 하나 업데이트 |
| 기업 실적 발표 때 | 이전 가설과 실제 실적 비교 | 맞은 점·틀린 점·다음 확인 지표 |
| 노트를 수정한 날 | 텍스트로 내보내기 | 개인 보관용 백업 |

60분 입문 루틴은 첫 질문을 만드는 연습이며, 매수·매도 결정을 완성하는 절차가 아닙니다.

## 진도와 노트 보관

- 학습 진도와 노트는 **접속한 주소의 브라우저 저장소**에만 저장됩니다. 동일 기기·동일 브라우저·동일 주소에서 이어서 사용하세요.
- 개발 미리보기에서 저장한 기록은 게시된 사이트로 자동 이동하지 않습니다.
- 브라우저 데이터 삭제, 시크릿 창 종료, 다른 기기·브라우저 사용 시 기록이 없을 수 있습니다.
- 기업 분석 노트는 현재 한 장입니다. 다른 기업으로 내용을 바꾸기 전에 **텍스트로 내보내기**로 보관하세요.
- 내보낸 텍스트를 앱으로 자동 가져오는 기능은 없습니다. 필요하면 내용을 복사해 노트에 붙여넣으세요.
- GitHub에 앱 소스를 저장해도 개인 진도와 노트는 함께 백업되지 않습니다. 개인 투자 노트는 별도 개인 폴더에 보관하세요.

## 자료 업데이트와 기능 범위

- **투자 훈련실**: IONQ·NVDA·VOO·QQQM·AAPL·MSFT·AMZN·GOOGL·META·TSLA를 이름이나 티커로 검색합니다. Yahoo Finance의 배당·분할 조정 일별 가격을 수록했으며 데이터 마지막 날짜는 2026.09.18입니다. 자동 갱신하지 않습니다.
- **과거 시점 훈련**: 미래 차트를 숨기고 판단 이유를 적은 뒤, 남은 현금의 25% 매수·보유분의 25% 매도·유지 중 하나를 선택합니다. 다음 거래일 조정 종가에 가상 체결 후 그날까지 공개합니다. 남은 기간 보유 후 결과를 바로 확인할 수도 있습니다.
- **전략 백테스트**: 동일 초기 현금으로 일괄매수·21거래일 간격 4회 분할매수·20일 이동평균 전략을 비교합니다. VOO 기준선도 함께 표시하며 수익률·최대 낙폭·매매 횟수·비용을 확인합니다.
- 훈련은 가상 단위를 이용한 총수익 근사 계산입니다. 현금 이자·추가입금·세금·환율·종료 청산비용은 제외합니다. 이동평균은 전일까지의 가격으로 신호를 계산하고 다음 종가에 거래합니다. 오늘 선택한 종목으로 과거를 보기 때문에 선택 편향과 과적합에 유의하세요.
- IONQ는 합병 전 SPAC 시세를 훈련에서 제외해 2021.10.01부터 제공합니다. 각 종목의 실제 수록 범위는 화면에 표시합니다. 당시의 뉴스와 재무제표까지 재현하는 기능은 없습니다.
- 완료한 훈련 기록과 판단 이유는 이 브라우저에 최근 100개 저장하고 JSON 파일로 내보낼 수 있습니다. 진행 중 훈련은 새로고침하면 초기화됩니다. 다른 기기와 동기화하지 않습니다.

- **실제 종목 분석** 메뉴에는 IONQ·NVDA·VOO·QQQM 학습 사례가 있습니다. 실제 발표 수치, 계산 예제, 확인 질문, 퀴즈와 내려받을 수 있는 연습지를 제공합니다. ETF 중복 노출 계산기는 가상 비중으로 시작하며 입력을 저장하거나 전송하지 않습니다.

- 자료는 선별한 교육 콘텐츠입니다. 자동 뉴스 수집, 실시간 시세, 자동 매매 기능은 없습니다.
- 현재 자료의 확인 기준일은 2026년 9월 21일입니다. 기업 분석 시에는 원문 사이트에서 최신 회계기간 자료를 선택하세요.
- 별도의 정기 알림은 아직 설정되어 있지 않습니다.
- GitHub 변경 사항은 게시된 앱에 자동 반영되지 않습니다. 앱을 수정한 뒤 별도 게시 과정이 필요합니다.
- 업데이트를 요청할 때는 이 프로젝트에서 수정할 메뉴와 원하는 동작을 설명하면 됩니다.

## 소스 구성

외부 빌드 도구 없이 동작하는 HTML·CSS·JavaScript 앱입니다.

- `dist/index.html`: 기본 화면과 메뉴
- `dist/style.css`: 반응형 화면 스타일
- `dist/app.js`: 수업, 퀴즈, 계산, 개인 노트
- `dist/research.js`: 기업 분석 자료와 학습 가이드
- `dist/cases.js`: 실제 기업·지수 ETF 학습 사례와 중복 노출 계산
- `dist/history.js`: 출처·조회일을 포함한 과거 조정주가 묶음
- `dist/training.js`: 종목 검색, 시점 훈련, 백테스트 계산과 기록
- `.openai/hosting.json`: 기존 Sites 게시 프로젝트 연결 정보

로컬 개발 미리보기:

```sh
python -m http.server 5173 --bind 127.0.0.1 --directory dist
```

그다음 `http://127.0.0.1:5173/`에서 확인합니다. JavaScript 변경 시 `node --check dist/app.js`와 `node --check dist/research.js`로 문법을 확인할 수 있습니다.

투자 학습용 콘텐츠이며 수익을 보장하거나 특정 종목의 매매를 권유하지 않습니다.

### 차트 읽기 & 용어집

메뉴에서 읽는 순서, 가상 캔들·추세 그림, 대표 패턴 6가지, 이동평균·RSI·MACD·볼린저밴드·ATR의 숫자 예제와 한계를 확인할 수 있습니다. 30개 용어는 한글·영문·설명으로 검색할 수 있습니다. 각 지표에 공식 학습 원문 링크가 있으며 내 종목 적용 질문에서 훈련실로 이동할 수 있습니다. 도식과 숫자는 학습용 가상 예제이며 실시간 기술적 분석이나 패턴 탐지 기능은 아닙니다. 콘텐츠: `dist/chart-guide.js`.

### 확장 학습 자료실

지식 라이브러리에 29개 공개 자료의 한국어 학습 안내, 읽을 구간, 적용 과제, 해석상 한계를 정리했습니다. 분야·키워드 검색과 6주 학습 순서, Markdown 안내서 다운로드를 제공합니다. 원문은 공식 출처에서 열람하며 원문 전체를 복제하거나 실시간으로 수집하지 않습니다. 확인일: 2026-09-22. 콘텐츠는 `dist/reading.js`에 있습니다.

모든 29개 자료에 쉬운 한 줄 설명, 가상 숫자 예제, 관심 종목 적용, 용어 풀이, 확인 질문과 펼쳐 보는 해설을 추가했습니다. `dist/easy-reading.js`에서 관리하며 다운로드 안내서에도 포함됩니다. 가상 예제는 실제 공시·시세와 명확히 구분합니다.

학습 안내서 다운로드는 한글 글꼴이 포함된 PDF로 제공합니다. 재생성: node scripts/export-reading.cjs 실행 후 reportlab이 설치된 Python으로 scripts/build-study-pdf.py를 실행합니다. 최종 배포 파일은 dist/study-guide.pdf입니다.
